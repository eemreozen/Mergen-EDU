# Mergen Backend Service

Bu dizin, **Mergen** projesinin backend servislerini barındırmak üzere ayrılmıştır.

## 🎯 Planlanan Yetenekler
- Kullanıcı ve Oturum Yönetimi (Auth & Sessions)
- Yapay Zeka Rota Oluşturucu (AI Roadmap Engine & Prompting)
- Yol Haritası İlerleme ve Veritabanı Kalıcılığı (Roadmaps Persistence)
- Danışman Asistan API Entegrasyonu (Advisor Agent Services)
